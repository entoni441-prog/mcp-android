## Исходное состояние

1. Окно ChatGPT `PID 15208` и **16** процессов `ChatGPT.exe` были запущены до испытания; `ownedByNexus=false`.
2. `close_window({pid:15208,title:"ChatGPT",ownerRequested:true,onUnsaved:"ask"})` вернул `closed:true,by:"owner_request",prompt:null`. После этого окна ChatGPT уже не было, но 16 фоновых процессов оставались.
3. Перед завершением фоновых процессов выполнена проверка `Get-CimInstance Win32_Process`: все **16/16** процессов имели один установленный путь `C:\Program Files\WindowsApps\OpenAI.Codex_26.1029.7803.0_x64__2p2nqsd0c76g0\app\ChatGPT.exe`, сеанс 1 и единое дерево с корневым PID `15208`.
4. В рамках явного разрешения владельца выполнено адресное завершение только этого проверенного дерева `ChatGPT.exe` с повторной сверкой пути, PID и времени создания. Получено `COLD_BASELINE_PASS`: `initialCount=16`, `remainingCount=0`.
5. Независимые `list_processes(nameFilter:"chatgpt")` и `list_windows` подтвердили **0 процессов и 0 окон** ChatGPT непосредственно перед запуском. Другие приложения не закрывались.

## Реальный cold-start через установленный NEXUS

1. `open_app({app:"chatgpt"})` вернул **`started:true`, `app:"chatgpt"`, `via:"discovered"`, `pid:16124`, `createdByNexus:{windows:["ChatGPT"],tabs:[]}`**.
2. `list_windows` подтвердил новое отдельное окно **ChatGPT PID 16124**. `list_processes`: новый корневой PID `16124` отмечен `ownedByNexus:true`; другие дочерние процессы не помечались чужими окнами или произвольно присвоенными объектами.
3. `window_info({pid:16124})`: видимое окно класса `Chrome_WidgetWin_1`, rect `x:113,y:87,w:527,h:605`; первоначально `foreground:false`.
4. `focus_window({pid:16124})` → **`focused:true,method:"titlebar_click",hwnd:6752420`**; безопасный зонд заголовка `ok:true,control:"Group",nativeVerified:true`. Нативная активация UIA вернула `MethodInvocationException`, поэтому использован уже принятый контролируемый titlebar fallback.
5. Повторный `window_info`: **`foreground:true`**, PID 16124, окно ChatGPT. `inspect_ui({pid:16124,maxDepth:3,maxNodes:45,includeText:false})` — **7 узлов**, чтение дерева UIA успешно; пользовательские тексты не читались.
6. NEXUS Host остался Online, Gateway HTTP 200. Никаких сообщений в чат не отправлялось, авторизация/аккаунт и параметры безопасности не менялись.

## Вывод и ограничения

**NX-03 FULL PASS** для реального обнаружения, **холодного запуска из подтверждённого нулевого состояния**, открытия и фокусировки окна, чтения UIA и корректного ownership созданного окна. Не повторять этот сценарий без новых условий.

Полное прекращение фоновых процессов через GUI не гарантируется: именно поэтому cold baseline контролировался отдельно.
