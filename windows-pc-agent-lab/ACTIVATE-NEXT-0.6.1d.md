## Откат

При критической регрессии остановить supervisor и Host по текущим проверенным PID (без /t), восстановить ровно пять файлов из указанного бэкапа, сверить все SHA256, запустить существующую задачу `NEXUS-Host-Run`, подтвердить health/соединение и восстановленные хэши. Не менять Gateway, scheduled tasks, owner approvals, `power` или security.

Адресный откат одного дефекта — только через `git revert` его подтверждённого коммита в **отдельной исходной ветке**, тесты, новый манифест и отдельное разрешение на установку. NX-13 и NX-21 делят `uia-script.mjs`; нельзя заменять весь файл старой версией при откате одного из них.
