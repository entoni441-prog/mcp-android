## Адресная замена (ТОЛЬКО после разрешения)

1. Убедиться, что нет активного ввода или работы владельца. Сверить **текущие** PID Host и supervisor с реальными путями; старые PID из отчётов не использовать.
2. Штатно остановить supervisor, затем Host по точным текущим PID, **без /t**. Не создавать owner-stop/host-off. Не менять Windows Task Scheduler, Gateway, Wrangler, policies, capabilities, `power` и систему подписей подтверждений.
3. Заменить **только пять** runtime-файлов из проверенной immutable source-копии. Проверить SHA256 установленных файлов против манифеста. `discover.mjs`, `runner.mjs`, все тесты и остальные файлы Host оставить без изменения.
4. Запустить **существующую** задачу `NEXUS-Host-Run` через Планировщик; не запускать новый node вручную и не создавать новую задачу. **Обязательно проверить восстановление supervisor:** новый PID и командная строка соответствуют действующей конфигурации, supervisor действительно работает после запуска Host. Если supervisor не поднялся, автоматическое восстановление до следующего входа может не работать — **STOP и откат**.

- NX-21 — **обязательный реальный E2E на компьютере владельца**, CI его не заменяет: `steam.exe` → `steamwebhelper.exe`, проверить живую PID ancestry, `createdByNexus`, `list_processes`, cleanup без присвоения чужого окна; неизвестная ancestry, уже запущенный в трее Steam и восстановленные вкладки остаются fail-closed. Рабочую Steam-сессию владельца не завершать. Если реальный Steam недоступен, отметить **BLOCKED**, а не PASS.
- NX-03, NX-26 и PWA focus не входят в эту сборку. Не помечать PASS. Самовосстановление C.5, загрузки, буфер и другие ранее прошедшие проверки не повторять без причины.
