# NEXUS — управление Edge и вход в Google Flow: блокер и ТЗ
Дата: 8 ноября 2026. Статус: OPEN / реальная приёмка НЕ выполнена.

## Цель
Добиться надежной работы NEXUS с обычным Microsoft Edge и Google Flow: агент видит разрешённый пользовательский интерфейс, выбирает аккаунт одним проверенным кликом, а владелец при необходимости подтверждает авторизацию Google на телефоне. Основной Live остаётся в чате ChatGPT на Samsung. Не требовать отдельную установку Google Flow или изменение настроек безопасности Google.

## Отчёт другого чата (со слов пользователя, не новая диагностика)
- Google Flow был открыт через NEXUS, доступ к Windows подтверждён.
- Во встроенном браузере NEXUS Google отклонил вход с сообщением о небезопасном браузере. Повторять эту тупиковую авторизацию не следует.
- В обычном Edge Google sign-in/account chooser открылся, но NEXUS не смог надежно получить изображение или определить элемент выбора аккаунта; клик не выполнен.
- Одновременно работала другая NEXUS-сессия; она не была прервана.
- Пароль не запрашивался, безопасность не менялась. Авторизация НЕ завершена.
- После завершения задачи осталась одна вкладка Edge, созданная NEXUS, которую не удалось автоматически закрыть.

## Диагностика без риска
1. Проверить свежий checkpoint, NEXUS connection_status, host_diagnostics, capabilities и owner pause/lease; вторую сессию не сбрасывать.
2. Проверить Edge PID/HWND, владение вкладкой, точное окно, UIA tree, browser/CDP, screen-frame mapping и актуальность кадра. Развести ошибки «нет изображения», privacy-redaction, stale frame, wrong window, blocked browser target, policy и параллельную сессию.
3. Не обходить правила Google, антибот, пароль, MFA, WebAuthn. Не передавать секреты или приватный кадр модели; owner-only подтверждение отдельно.
4. После диагностики разрешенного Edge проверить один безопасный клик по однозначно определённой кнопке аккаунта. Не делать повторные клики при неопределённом результате. MFA выполняет владелец.
5. Восстановить cleanup только созданной NEXUS вкладки Edge после задачи; другие вкладки и несохранённые данные не затрагивать.

## Критерии приёмки
- [ ] Google Flow открыт в стандартном Edge; встроенный браузер, который Google блокирует, не используется для авторизации.
- [ ] NEXUS видит актуальное состояние нужного окна/вкладки Edge и достоверно определяет кнопку Google Account chooser.
- [ ] Один проверенный клик по аккаунту выполнен; собственный пароль или MFA владелец вводит только в официальном интерфейсе Google.
- [ ] Реальный успешный вход в Flow подтверждён; если блокируется извне, причина зафиксирована, без ложного PASS.
- [ ] Встроенный Live в чате на Samsung не перекрывается и допускает нужное управление.
- [ ] Параллельная сессия NEXUS не нарушена, owner STOP и безопасность сохранены.
- [ ] Вкладки/окна, созданные NEXUS, корректно закрыты без затрагивания вкладок владельца.
- [ ] Сохранён GitHub checkpoint и фактический E2E отчёт PASS/FAIL без секретов.

## Ограничения
Не менять main, production Gateway, рабочий Host, политику безопасности без отдельного разрешения. Не начинать разработку заново; сначала точная read-only диагностика. Не выдумывать, что функциональность Google Flow уже работает.
